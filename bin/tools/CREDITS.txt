---- HOW THE MINIMAL FILE SET WAS DETERMINED (measured, not guessed) ----
  1) imgkit.exe / make_ext4fs.exe / simg2img.exe / img2simg.exe were copied
     alone into a clean temporary folder (no DLLs there) and executed:
       imgkit.exe      -> printed its full usage text, exit code 2 = loads fine
       make_ext4fs.exe -> actually read an fs_config and started building = loads fine
       simg2img.exe    -> printed its version banner, exit code 1 = loads fine
       img2simg.exe    -> exit code -1073741515 (0xC0000135, DLL not found) = missing runtime
  2) After adding cygwin1.dll: img2simg.exe printed its usage; a 1 MB
     img2simg -> simg2img round trip produced an identical SHA256 (lossless).
  3) Conclusion: imgkit / make_ext4fs / simg2img need no extra DLL;
     img2simg.exe needs cygwin1.dll, so cygwin1.dll ships too.
     adb: adb.exe alone can run "version" and "start-server", but USB device
     enumeration needs AdbWinApi.dll / AdbWinUsbApi.dll (the official Windows
     release ships all three), so all three ship together.
